# Morse Code Trainer

A trainer to identify and understand morse code.

## Set Up Dev enviroment
**Prerequisites**
- Python >= 3.11 (cpython or pypy)
- pip or uv

1. Generate the virtual enviroment `python3 -m venv .venv` or `uv venv`
2. Activate the venv `source .venv/bin/activate`
3. Get all the packages `uv sync` or `pip install .`

Edit to your hearts content.
